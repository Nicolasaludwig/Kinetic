# Kinetic
A Kinetic é uma startup voltada para dançarinos independentes, coreógrafos e criadores de conteúdo de dança. O problema que eles enfrentam é que aprender coreografias por vídeos comuns obriga o dançarino a parar toda hora para voltar o vídeo, espelhar a imagem mentalmente e contar os tempos musicais sem auxílio visual.
